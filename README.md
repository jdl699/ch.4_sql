Assignment on MySQL CH.4 Database

Queries on the Sakila Database

Summary

In this assignment, SQL queries are used to fetch data from the Sakila database. Data is fetched from specific fields from various tables, filtered according to requirements, and sorted for ease of understanding. The assignment has several queries for fetching organized information on movies, actors, customers, and rental information.

# MySQL CH.4 Dynamic Webpage
Vendor Invoices

Summary

The program will connect to the database and retrieve data about vendors and their invoices. Users may type a vendor ID to view the invoices for the particular vendor or type 'ALL' to view the invoices for all vendors. The vendor's name, invoice number, date, and total are displayed. In addition, the program will sort the invoices according to the vendor and total. An additional section of the program displays the invoices with a total of $1,000 or higher.
